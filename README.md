> ### РЕАКЦИЯ АНТИВИРУСОВ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret требуется WinDivert — инструмент, который перехватывает и фильтрует трафик.
> Его применяют как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы классифицируют файлы WinDivert как ПО повышенного риска или хакерские инструменты, после чего удаляют их либо помещают в карантин. В названии такого обнаружения обязательно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Касперском для этого есть параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы умеете аккуратно настраивать исключения, рекомендуется добавить исключение; если не уверены в своих действиях, отключите обнаружение PUA.

## ⚙️Как пользоваться

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите «Использовать безопасный DNS» и укажите поставщика DNS, отличного от варианта «Поставщик по умолчанию»
    * В Firefox откройте «DNS через HTTPS», установите режим «Персональный», затем выберите «Выбрать провайдера/поставщика» и вручную укажите URL. Например, подойдёт `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * Владельцам роутеров Keenetic нужно включить параметр «Транзит запросов». Если он отключён, при настройке и использовании Secure DNS на компьютере могут возникнуть проблемы

2. Загрузите архив в формате zip/rar со [страницы актуального релиза](https://github.com/GrandeurChief/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте пункт «Разблокировать». Пользователи 7-Zip или PeaZip могут не выполнять этот шаг

4. Извлеките архив в каталог, путь к которому не содержит кириллицы и специальных символов

5. Откройте подходящий файл
    * Чтобы определить рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы настроить автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной режим подходит для проверки стратегий. Их работоспособность зависит от множества условий. **Перебирайте стратегии ALT, FAKE и другие, пока не найдёте вариант, который работает у вас**

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные возможности:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаляет из служб стратегию и WinDivert
  - **`Check Status`** — показывает состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — меняет режим обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — меняет режим обхода ресурсов, перечисленных в `ipset-all.txt`.  
  Эта настройка полезна при проверке ресурса, который открывается без zapret, но не работает вместе с ним.  
  В скобках отображается активный режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP-адреса в списке
    - `any` — фильтрация применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включает или отключает автоматическую проверку обновлений
  - **`Replace active fakes`** — заменяет указанный активный фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загружает из репозитория актуальную версию `ipset-all.txt`
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ищет доступные обновления
  - **`Run Diagnostics`** — проверяет распространённые причины неработоспособности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, если приложение внезапно перестало работать
  - **`Run Tests`** — открывает утилиту проверки работоспособности стратегий:
    - `Standard tests` — проверяет сайты, указанные в `utils/targets.txt`
    - `DPI checkers` — выполняет проверку DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### После открытия скрипта `general*` ничего не происходит

- При ручном запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe для обхода — его можно увидеть на панели задач.  
Если программа не появилась, обратитесь к [#522](https://github.com/GrandeurChief/zapret-discord-youtube/issues/522)

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните в консоли следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезапустите компьютер

### Не открывается веб-версия Telegram
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из запустившегося Блокнота
  - В появившемся каталоге откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените предыдущую аналогичную запись
  - Сохраните изменения и снова проверьте соединение. Если проблема осталась, удостоверьтесь, что изменения в `hosts` действительно сохранились.

#### Работоспособность не гарантируется. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/GrandeurChief/tg-ws-proxy) либо любой публичный.

### Обход перестал работать или не запускается

> [!IMPORTANT]
> **Со временем отдельные стратегии могут терять работоспособность.**
> Стратегия способна работать определённый период, а после обнаружения перестать помогать.
> В репозитории собрано множество вариантов обхода. Если ни один из них не работает, создайте собственную стратегию на базе одной из имеющихся, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что диагностика не показывает ошибок

- Проверьте, присутствует ли адрес нужного ресурса в перечне доменов или IP-адресов

- Переберите остальные стратегии, включая **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация приведена в [#765](https://github.com/GrandeurChief/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Выберите `service.bat` -> `Run Diagnostics`, устраните найденные ошибки и в конце нажмите Y
- Удалите каталог с zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/GrandeurChief/zapret-discord-youtube/releases), выбрав архив `zapret-discord-youtube-...`
- Откройте свойства архива через контекстное меню. Если справа внизу доступен пункт «Разблокировать», отметьте его и нажмите «Применить» -> «ОК»
- Распакуйте файлы в новый каталог в корне диска, избегая пробелов и специальных символов в пути
- Поочерёдно запускайте разные скрипты `general`, то есть стратегии, и проверяйте доступ к интернет-ресурсам. Если они не открываются, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- Когда найдёте рабочий вариант, добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### При включённом zapret не запускается игра или приложение

- Убедитесь, что в service.bat параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Другие значения могут повлиять на доступность ресурсов, которые вы не планировали фильтровать.

### Античит обнаруживает WinDivert

- Воспользуйтесь инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert остаётся в системе

1. Определите имя службы, выполнив в командной строке Windows (Win+R, `cmd`) команду:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, в том числе если прежняя раньше работала.
- Дополнительные сведения есть в [#251](https://github.com/GrandeurChief/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён и настроен
- Сначала желательно определить стратегию, при которой открывается YouTube, и запустить именно её
- Откройте `service.bat` -> `Run Diagnostics` и воспользуйтесь функцией очистки кэша Discord
- Снова запустите Discord и проверьте, устранила ли очистка проблему
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно пользоваться ею
- Если браузерная версия также недоступна, повторно проверьте все стратегии. Иногда одна стратегия открывает YouTube, но не помогает с Discord
- Подробности также обсуждаются в [#252](https://github.com/GrandeurChief/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь приложением [tg-ws-proxy](https://github.com/GrandeurChief/tg-ws-proxy)
- Другой вариант — бесплатные публичные MTProto-прокси из интернета

### Не запускаются игры

Игр существует много, поэтому исследовать и исправлять работу каждой из них невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, затем активируйте `Game Filter`
- если результата нет, дополнительно попробуйте режим `ipset any`

Учтите, что `ipset any` может нарушить доступ ко многим сайтам, поэтому не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если эти действия не помогли, откройте тему в разделе [Discussions](https://github.com/GrandeurChief/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

## 🗒️Как добавить адреса других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; их поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда IP сети присутствует в `ipset-all.txt`, но отдельный домен этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключения IP-адресов и подсетей
  - Файлы вида **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
